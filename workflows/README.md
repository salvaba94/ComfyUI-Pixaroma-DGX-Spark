# Workflows

This directory is mounted into ComfyUI as:

```text
/app/ComfyUI/user/default/workflows
```

## Pixaroma Workflows

The workflows under `Pixaroma/` were downloaded from:

```text
https://workflows.pixaroma.com/
```

They are kept as extracted ComfyUI workflow files for local use. Original downloaded ZIP archives are local build/download artifacts and are not committed.

## Trellis2 Workflows

The workflows under `Trellis2/` are example workflows copied from the installed `ComfyUI-Trellis2` custom node, plus local Trellis2 workflow variants used with this Docker setup.
